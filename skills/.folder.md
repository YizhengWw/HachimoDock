## Architecture
- 2026-08-06 configurable-exit copy contract: generated packages still leave
  out device navigation and reserve the factory-default SW1 gesture, but their
  screen/footer copy must say “全局键退出” instead of claiming SW1 is always
  bound. The contract explicitly allows users to remap exit to multiple global
  gestures or leave it unbound.
- 2026-08-05 global-exit generation contract: the shared `petui` Skill installed
  into Codex, Claude, Cursor, and other supported Agents no longer writes
  `page_main/page_back` or any package navigation action. Default SW1 short is
  reserved for global exit; generated games use SW3 for start/restart, tools
  use SW3 for their primary action, and the validator rejects both SW1 gameplay
  collisions and component-authored system navigation.
- 2026-08-04 historical joystick-generation contract (superseded 2026-08-05):
  `petui` added all four joystick directions with legacy-compatible left/right
  event names. Its former package-owned SW3 exit rule has now been replaced by
  the global-exit contract above.
- 2026-08-03 component-upgrade identity rule: `petui` now distinguishes new
  generation from optimization/repair. Existing components must retain their
  exact `component.json.id`, publish into the same content-addressed version
  chain, and tell the user to refresh plus “保存并同步” the same card so the
  device package is actually replaced.
- 2026-07-29 required-vars contract: the generator prompt and deterministic
  validator now require `runtime/widget.json.vars` to be an object keyed by
  variable id, with `{}` mandatory when no variables are needed, preventing
  generated packages from reaching the board with missing/array/null vars.
- 2026-07-28 P4 page-contract correction: the generator Skill, prompt/slot
  references, validation script, and multi-page examples now require page
  objects to contain only a bounded `id`. Human-readable page copy remains in
  dashboard `switch_page`, preventing generated and built-in packages from
  passing desktop checks but being rejected by P4 as an unsupported field.
- 2026-07-27 component button-scope update: generated `buttons.json` mappings apply only while their component is open and never replace the device-page encoder enter/back defaults.
- Scope: skills
- Function: Bundled coding-agent skills that Pet Manager installs into detected local Agents. `petui` turns natural-language component requests into validated P4 `.clawpkg` packages and atomically publishes them to the formal local component library.
- Sync: if this folder changes, update this file immediately.
- Reuse: Skill instructions reuse `references/contract.md` plus the deliberately incomplete `references/patterns.md`, then invoke the deterministic validator/publisher under `scripts/`. Distributable Skills must not contain complete component packages because agents tend to copy their mechanics and layout.
