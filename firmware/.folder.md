# 固件目录

0.7.51-p4 使用统一 4M UART 配置，供 Windows/macOS 客户端及完整烧录包共用。
Windows PlatformIO 环境仅作为兼容别名继承默认环境，不再覆盖通信速率。
v1 与 v3 独立编译并锁定各自依赖，界面、分区及输入不变。`scripts/platformio_chip_images.py` 为应用和 Bootloader 写入芯片范围；`main/pet_p4_image_compat.h`、`tools/p4_image_compat.py` 与 `tools/flash_checked.py` 阻止跨芯片升级/擦除。

- `main/`：设备运行逻辑。
- `components/`：板级驱动及适配组件。
- `tools/`：内置组件处理及完整出厂镜像生成工具。
- `tests/`：主机测试与手动设备测试。

内置素材和组件从 `../pc/` 读取。构建与烧录方法见 [README.md](README.md)。
