# Folder Plan: ref/src/dashboard

## Architecture
- 2026-08-03 module-order update: `DeviceDashboard` now renders the complete
  Agent/appearance card immediately after device status and the complete button
  configuration card after it; voice input remains the final default-open card.
  No module state, actions, or internal composition changed in the swap.
- 2026-08-03 immediate ASR activation: `VoiceAssistantPanel` distinguishes its
  silent initial readiness read from a real Volcengine configuration update.
  The latter asks `DeviceDashboard` to rearm voice only when P4 voice is
  enabled and the exact USB board is online, so newly saved credentials work
  without restarting the desktop client.
- 2026-08-03 native Accessibility authorization recovery:
  `VoiceAssistantPanel` keeps background status diagnosis and explicit recheck
  silent. Its authorization action requests Apple's native consent alert, and
  never opens a competing settings deep link; the system alert owns its button
  and Accessibility toggle-page routing.
- 2026-08-03 visible-Agent naming and recovery update: the voice panel renders
  `ChatGPT（Codex）` or `Claude` from the frozen utterance route in progress,
  transcript, and platform recovery copy. Legacy error wording remains
  detectable so upgraded clients still offer the correct recovery guidance.
- 2026-08-01 Claude terminal parity coverage: the Session-feed reducer now
  verifies that an already visible Claude task ending through `idle` receives
  the same fixed 60-second completion lifetime as explicit `done`/`error`.
- 2026-08-01 visible-card continuity correction: stream resets no longer clear
  the current queue before bootstrap events arrive, and `useP4SessionSync`
  derives active IDs from the exact visible cards so firmware retention and
  local dismiss/clear actions share one meaning.
- 2026-08-01 Session lease/navigation reliability: `useAgentSessionFeed`
  preserves event lifecycle across metadata-only Agent snapshots and tolerates
  short scanner omissions. `useP4SessionSync` renews `session/current` every
  four seconds and forces a serialized desktop-location request for every
  encoder selection, including a repeated exact Session ID.
- 2026-08-01 Session orchestration extraction: `useAgentSessionFeed` owns the
  persistent 750ms event stream, five-second snapshots, Agent-isolated reducer,
  and terminal-card expiry ticks. `useP4SessionSync` owns the visible-card
  selection lease, encoder events, exact desktop location notices, and
  serialized P4 Session downlinks, leaving `DeviceDashboard` as the page-level
  composition boundary.
- 2026-07-30 appearance-picker latency update: the Agent appearance modal
  opens from the cached catalog immediately, then refreshes disk-backed
  appearances in the background without waiting for Bridge profile or Agent
  CLI scans.
- 2026-07-30 P4 USB-only status cleanup: the dashboard no longer exposes the
  unsupported USB-to-Wi-Fi form or Wi-Fi reachability chips. Device status and
  follow eligibility now use only a verified USB connection; firmware,
  diagnostics, recovery, and unbind actions remain unchanged.
- 2026-07-29 USB-only follow gating: `ChannelMatrixCard` enables the Follow
  action only for a verified USB connection and explains the cable requirement
  directly in the disabled control instead of treating WiFi availability as a
  writable follow transport.
- 2026-07-28 P4 default-navigation v4 update: the global map now binds SW2
  short to Component Center and SW3 short to Back (Cancel), while encoder long
  becomes unbound. The same action catalog remains available for user edits,
  and component-local mappings still take priority only while a component is
  open.
- 2026-07-28 unique button-action policy: every non-disabled P4 action has exactly one gesture owner. Used actions remain visible in other selects but are disabled with an “已绑定：<手势>” hint. All short-press selects also show the second-position voice-input option disabled as “需要长按”; pure helpers normalize cached/downlink maps so stale duplicates cannot bypass the UI.
- 2026-07-28 simplified P4 action-contract update: all SW short/long rows remain visible, but the selectable menu removes Continue Agent, negative-screen tap/hold proxies, current-component action, and screen toggle. Custom prompt is first and voice input second on eligible long presses; labels become Previous/Next, Confirm, and Back (Cancel). Fresh defaults bind SW1 long to voice input, SW3 short to Component Center, and encoder press/rotation to confirm/back/previous/next, leaving every other SW gesture unbound.
- 2026-07-28 Codex Accessibility recovery update: voice delivery failures caused by an unreadable/unfocused macOS Codex composer now render an inline recovery guide with the exact System Settings path, a direct “打开辅助功能设置” action, permission recheck feedback, and the existing empty/focused-composer retry advice.
- 2026-07-28 cross-platform foreground-input Tips: the same recovery card now detects the desktop platform. macOS Dev builds show the repo-relative debug executable plus the Accessibility “＋”/`⌘⇧G` flow; Windows builds show the target-native `.exe` path and explain that UI Automation requires matching integrity levels rather than an Accessibility allow-list.
- 2026-07-28 verified-permission recovery: macOS foreground failures first perform a silent trust check. Confirmed authorization switches the card to a success diagnosis that explicitly prevents repeat System Settings/password work and points to task/composer conditions; only genuinely untrusted processes retain the settings/add-file actions.
- 2026-07-28 compact per-button prompt update: `BoardButtonPanel` removes the duplicated outer Card header and owns one 38px title/count/sync toolbar with a compact USB action; successful board-read feedback becomes a 26px strip. Four physical-order cards each include a standalone accessible SVG and place short/long configuration directly beneath it. Choosing `agent_prompt` reveals an independent bounded Code Agent textarea inside that exact gesture row; the encoder also retains left/right rotation.
- 2026-07-28 Agent visibility update: `ChannelMatrixCard` keeps every supported Agent row visible after discovery, marks missing CLIs with a dashed muted state, and disables appearance/follow actions until a rescan detects the channel. The containing dashboard Card owns the shared manual rescan action.
- 2026-07-28 ten-gesture voice-layout update: `BoardButtonPanel` keeps the full P4 deck SVG above four matching physical-order groups for SW1/SW2/SW3/encoder. Every button exposes short/long configuration, the encoder additionally retains left/right rotation, and SW1 long defaults to PTT. Each PTT row reflects enablement with a status chip while Voice Assistant owns the shared switch; `.hold` remains internal to the ACK-gated board map.
- 2026-07-27 cancellable appearance-transfer update: `ChannelMatrixCard` places a shared danger `Button` beside the inline USB progress meter. It requests the context-owned backend cancellation, shows a stable “正在中断…” state, and reports cancellation without mutating the followed Agent or active appearance.
- 2026-07-27 balanced button-workspace history: the former seven-gesture 45/55 layout is superseded by the 2026-07-28 image-first ten-gesture layout. Conditional custom-prompt values remain behind a default-off accessible “显示内容” switch.
- 2026-07-28 input-reset cache update: `DeviceDiagnosticsModal` awaits the parent dashboard's board-config refresh after an ACKed input reset, so the success state cannot leave a stale pre-reset mapping in the client cache.
- 2026-07-27 gesture-model history: the temporary short-only switch model is superseded; SW1/SW2/SW3 now each expose short/long rows and SW1 long owns the default PTT selection.
- 2026-07-23 encoder-gesture update: `BoardButtonPanel` now renders four encoder rows—short press, long press, left rotation, and right rotation—and offers the same unified “切换屏幕” action on each configurable P4 gesture.
- 2026-07-23 MiMoCode update: `ChannelMatrixCard` renders detected MiMoCode installs as a fourth followable Agent and keeps the same appearance assignment/sync behavior as the existing channels.
- 2026-07-29 MiMoCode voice-input update: `VoiceAssistantPanel` distinguishes macOS MiMoCode `focused-input` from Codex/Claude visible submission, explains that release writes the final transcript at the captured terminal caret and presses Return, and renders a dedicated “MiMoCode 光标提交” badge.
