## Architecture
- 2026-07-31 P4 v9 ready-pack update: the prebuilder reads FFmpeg container
  duration, exports at most 225 H.264 frames across the full timeline, emits
  exact per-family `durationMs`, and writes 640x480/up-to-15fps/CRF27 Annex-B
  streams with aspect-fit letterboxing, the ESP decoder-compatible SPS, and
  one x264 thread/slice per access unit for stable tinyh264 decoding.
  Desktop and factory packaging consume that same hashed pack, so installation
  and device synchronization never perform media conversion.
- 2026-07-30 Windows UTF-8 and long-path update: shared PowerShell setup forces UTF-8 console/Python/locale state, isolates temporary files under a short ASCII sibling cache, rejects non-ASCII or overlong PlatformIO roots before ESP-IDF extraction, and can persist the sanitized core for the current user. Both release/dev desktop launchers consume the same environment contract.
- 2026-07-27 desktop packaging update: Tauri resources are staged from the target host's real Node executable plus a pinned, checksum-verified target-native FFmpeg static build and license/source notices; the preflight rejects Git LFS pointers and wrong-platform binaries, installs only the bridge's locked production dependencies, and can produce a resource-complete current-user NSIS installer from a cargo-xwin build.
- 2026-07-29 local macOS TCC identity update: `sign-macos-local-app.mjs` replaces Tauri's per-build CDHash designated requirement with a stable `com.petmanager.desktop` identifier requirement after local app bundling. `npm run build:mac:local` uses it so Accessibility permission survives subsequent local code changes; production release signing remains separate.
- 2026-07-22 P4 widget smoke update: transformed runtime JSON stays compact, acknowledged widget chunks use the same three-attempt idempotent retry policy as the desktop client so high-baud CH343 frame loss does not create false component failures, and screenshots cover countdown-complete plus tomato-rest boundary states in addition to each initial view.
- 2026-07-28 widget commit timing update: hardware smoke installs keep the commit waiter open for 15 seconds, matching the desktop client and the board's flash-backed multi-component catalog sync time.
