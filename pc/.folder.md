# 客户端目录

0.1.55：Windows 保留超时前的串口半帧，首次高速探测等待设备启动，
切速复用端口并释放 DTR/RTS。最近成功速率缓存于当前进程，连接诊断写入
现有 USB 日志。两端统一读取 `firmware/esp32-p4/firmware.bin`，兼容旧 2M 固件。

- `src/`：React 界面和测试。
- `src-tauri/`：Rust 后端、设备通信及 Node Agent 连接服务。
- `scripts/`：构建、资源准备及检查脚本。
- `skills/petui/`：组件生成 Skill。
- `builtin-clawpkgs/`、`public/terrier-clips/`：与固件共享的内置组件及形象。

开发和测试命令见 [README.md](README.md)。
