# PC 客户端目录

0.1.82：服务商独立 Key、可编辑模型名、默认豆包与 MiMo v2.6 Flash、按需联网口语回答、ASR 二次确认打断及西高地佩奇猪音色。公开包不含 Key/企业 CA；Tauri 最低 2.11.1，双端随包携带 ESP-SR 许可证。

Tauri + React 客户端负责 Agent 跟随、形象与组件管理、实时对话、智能家居及 PC 数据源。

- `src/`：界面、状态管理、视频生成流程及 Node 回归测试。
- `src-tauri/src/`：USB、语音、网络、米家协议和行情数据源的 Rust 实现。
- `src-tauri/bridge/`：本机 Agent 会话适配与运行时桥接。
- `builtin-clawpkgs/`、`public/terrier-clips/`：内置组件和默认形象资源。
- `skills/petui/`：组件生成与校验 Skill。
- `scripts/`：资源准备、打包、签名和回归工具。
- `docs/`：功能使用说明、协议与构建文档。

公开构建从 `npm ci`、`npm test`、`npm run build` 开始；平台工具及资源要求见 `docs/runtime-dependencies.md`。公开包不携带凭据、企业证书或固定代理地址。
