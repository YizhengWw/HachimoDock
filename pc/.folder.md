# Desktop source (0.1.168)

- src: React UI, generation pipeline and regression tests.
- src-tauri: native device, audio, desktop integration and local configuration.
- src-tauri/bridge: local Agent session event bus and receipt handling.
- builtin-clawpkgs / new-components: public widget packages and source assets.
- scripts: resource preparation, tests and public distribution checks.

`src-tauri/src/network_transport.rs` owns the Wi-Fi link: HMAC challenge/response, UDP discovery, and the paired-board registry (secrets in the OS credential store or a private 0600 file, endpoints in `network-devices.json`). It is a second connection source for `UsbSerialManager::connect_network`; the manager keeps one connection slot, USB wins, and assets, audio, widgets and firmware refuse a Wi-Fi link with an actionable message.

The bundled catalog follows the firmware factory list (28 components). Media
contract tests use independent offline fixtures under tests/fixtures. Official
community staging uses the same current catalog.

Public source uses user-provided credentials and per-computer networking settings. service_credentials.rs only rejects a legacy non-secret placeholder; it does not supply service defaults. Configure your own service keys in API settings. User configuration and caches are runtime data, never build inputs. See the repository README for build and release instructions.
