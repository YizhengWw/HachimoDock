# 客户端界面

内置西高地小狗的出厂默认音色为「佩奇猪 2.0」（`zh_female_peiqi_uranus_bigtts`）；未保存配置及恢复出厂人设使用新默认值，已保存音色/复刻音色/语速/音量保留，其他形象默认仍为 Vivi 2.0。回归在 `lib/persona-voice.test.js`。

首次服务商默认豆包，MiMo 默认 `mimo-v2.6-flash`。`ApiSettings` 保存按需联网开关；PC 保持原有对话记录，不另设联网结果、来源、日期列表，联网来源不发送到界面。共享使用说明区分双向固件可打断与旧固件等待说完。

`lib/api-configuration.js` 的服务商切换及自定义地址修改会清除未保存 Key 草稿，恢复目标服务/接口已保存 Key 的掩码和配置状态；没有对应凭据时才提示填写。`ApiSettings.test.js` 覆盖所有服务商组合，`scripts/test-settings-layout-browser.mjs` 验证实际表单；后端按服务/地址独立存储并选择凭据，界面不读取明文 Key。

`windows-realtime-transport.test.js` 检查 Windows 实时音频的 OVERLAPPED 打开、独立非继承事件、取消后等待完成、64 字节写入、拒绝原因日志及发送失败停止等源码契约；原生写入测试在 `src-tauri/src/usb_serial/live_audio_pacing.rs`，覆盖完整/部分写入、失败停止和不 flush，这些测试不替代 Windows 设备实测。

`component-center/StockWatchlist.jsx` 仅在行情组件详情弹窗展示自选股管理；`fixtures.js` 从内置组件读取清单/运行时/按键，默认内置顺序第一但不置顶；`library-order.js` 保留新增用户组件优先与同 ID 去重。中文/代码联想有 350 ms 防抖、输入法保护与旧结果隔离；点击结果验证行情后加入列表。列表持久化、每 2 秒行情与市场时区颜色判断在原生层完成。浏览器回归位于 `scripts/test-stock-watchlist-browser.mjs`。

`SmartHome.jsx` 位于组件中心下方：设备/房间筛选、能力详情、自然语言任务、确认与执行记录；连接账号后默认可用全部账号已授权设备和场景，无需逐项勾选。样式为 `smart-home.css`，纯显示逻辑与测试为 `lib/smart-home.js` / `.test.js`。执行权限由原生运行时校验，不依赖界面禁用状态。已连接卡片用实时对话、放歌/切歌/灯光窗帘示例说明使用方式；5 步以内直控，超过 5 步或保存任务时在实时对话中直接语音确认，不要求回到页面。

API 配置页将实时对话的作用范围放在标题副文案，并收紧使用说明间距；首页常用操作默认展开，可手动收起。
API 标题说明使用整行可用宽度，不再限制 88ch；宽屏保持一行，窄屏按实际宽度自然换行。智能家居欢迎页说明本地凭据与升级后重新授权，不触发 Mac 钥匙串读取。
默认完成提示音为四组三声（每组 650 ms，组间 400 ms），由 `scripts/generate-done-cue.mjs` 生成；`lib/done-cue.test.js` 校验实际音频的 12 个音段与时序。旧形象默认提示音在读取时更新，显式上传的音效保留。

本目录包含 React 页面、设备操作流程、组件校验和预览渲染，测试与功能模块放在一起。

`UsageHelp.jsx` 与 `lib/usage-help.js` 统一用户操作说明，当前设备的标准化按键映射经 DeviceContext 共享给首页、API 配置和人设弹窗。说明按当前配置显示，未同步时标注；不修改实际按键或语音协议。缺少配置时给出可执行的下一步，API 保存不等同云端测试通过。画廊及首页人设表单在临时跳转 API 配置时保留，配置更新事件刷新试听状态。

设备会话导航会合并连续的空列表提示，不影响有效会话切换。

切离设备页后保留控制器与连接监听，但不渲染隐藏控制台；仅保留正在编辑的人设表单，避免去配置 API 后丢失未保存输入。
形象卡片仅在选中、悬停或键盘聚焦时播放；生成结果保留至用户确认，
结果卡与通知同步关闭，并用完成轮次避免旧通知清除新任务。
窗口重新聚焦后的自动 Agent 探测间隔为五分钟，手动刷新不受限制。

形象生成支持刷新 Ark 视频模型列表、手动输入模型或接入点 ID，以及保存视频参数。
参考图版权/内容审核失败单独提示，不归为参数错误或模型不可用；共用参考图被明确拒绝后停止提交剩余动作，等待在途任务并保留成功结果，不影响下次使用新素材重试。回归测试覆盖提交/轮询拒绝、并发停止、部分成功和普通动作失败。
审核提示区分图片背景处理（Seedream 生图）和 Seedance 图生视频；仅在平台明确提到真人/人脸时归类人像，通用版权或隐私错误不自动判定人像。生成配置说明真人素材授权要求及当前未接入可信素材库的限制。排查结论见 `../docs/avatar-generation-moderation.md`。
图生视频参考图审核失败及生成配置页提供自行生成动态形象后上传 MP4 的替代路径，入口名称与形象画廊保持一致，并说明在详情页补充其他动作；不承诺外部生成能通过审核。
生成卡片将进度标为“已处理”，避免把未提交动作当作生成成功；审核拦截后的部分成功会在卡片和通知中明确提示。
未配置视频模型时，按模型版本、日期从当前列表选择最新 Fast 模型；保留已有选择，手动输入不被自动覆盖，无 Fast 模型时保持待选择。
列表仅供选择参考，不用目录查询故障替代实际调用权限判断；
模型拒绝缓存五分钟过期，手动刷新可以清除，允许权限开通后重试。
视频模型刷新按请求取消和 Key 归属隔离结果，不提交付费探测任务。

生成、模型列表与下载经 Rust 共享云服务证书设置；网络错误使用脱敏提示，不记录签名素材 URL。云服务网络设置同样覆盖 ASR/TTS，新连接生效，不影响本机 Agent 或设备直连。

设备与系统操作通过 Tauri 命令调用，Agent 状态通过本机连接服务获取。界面规范见 [design.md](../design.md)。

设备页新增 `dashboard/RealtimeChatPanel.jsx` 卡片与 `realtime_chat` 按键动作；`ApiSettings.jsx` 的「语音识别与合成」
卡片只保留一把豆包语音 Key，同时用于识别与合成，默认 ASR/TTS 2.0，不再提供版本/资源选择；「对话大模型」卡片提供 DeepSeek / 豆包 / MiMo 默认模型，均可修改模型名称或接入点 ID，留空使用默认值；MiMo 默认为 mimo-v2.6-flash。

`LlmNetworkSettings.jsx` 在对话大模型卡片提供本机网络设置（系统代理、直连、手动代理、可信 CA 导入），保存后才能测试火山与 DeepSeek；测试不发送 Key 或对话，访问被拒绝不显示成功。
契约测试见 `realtime-chat.test.js`、`lib/persona-voice.test.js`、`PersonaVoiceModal.test.js`。
