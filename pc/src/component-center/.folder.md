# 组件中心子组件

`StockScreenPreview.jsx`、`stock-preview.js` 和 `stock-screen-preview.css` 为行情组件卡片与详情提供 PC 专用的默认小米/阿里预览。可见时每 2 秒只读原生缓存，不额外取价、不改用户名单；缺行情显示破折号，缓存过期明确标记，只有价格与涨跌幅按 tone 着色。占位名单不进入组件包和设备数据。

`library-order.js` 保留用户组件按创建时间倒序、随后默认内置顺序的规则；内置行情列第一但不固定置顶，后续新增组件可以排在前面。同 ID 本地包与内置包去重。

`ComponentPreviewModal.jsx` 承载组件预览、按钮配置与同步；组件订阅 `stocks.watchlist` 或 ID 为 `stock-watchlist` 时展示 `StockWatchlist.jsx`。其他组件不挂载行情管理或轮询。

`StockWatchlist.jsx` 提供自动保存的股票列表、中文名称/代码联想、结果市场标识、增删排序和行情刷新。输入防抖，旧请求不覆盖新查询，输入法组词期间不请求；关闭弹窗不停止原生后台每 2 秒的行情更新。只有价格/涨跌幅使用原生 tone 颜色。
