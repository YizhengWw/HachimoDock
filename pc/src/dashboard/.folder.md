# 设备控制台

`RealtimeChatPanel` 保持普通对话记录，不额外展示联网结果或来源；设备查询提示由原生层发送。来源只留在原生工具链，不发送到界面。

本目录包含设备状态、按键配置、语音输入及确认发送、固件升级等界面模块。默认按键与固件及组件生成规范保持一致。

会话切换的空列表提示按连续操作合并，避免按住方向时重复弹窗；区分列表加载中与当前无会话。

按钮配置通过 `lib/usage-help.js` 从实际按键映射生成常用操作说明，未绑定、语音关闭与待同步状态均明确提示。实时对话卡片检查设备、当前人设、识别/合成和大模型配置，提供对应跳转或重试入口；语音输入说明区分追加草稿与确认发送。详细用法及日志折叠显示，开发路径只在开发模式显示。
