# 客户端工具

0.1.82：双端公开安装包同时携带 MiLoCo 与 ESP-SR 许可证；不启用 internal-network、不注入 Key/企业 CA。

- `prepare-desktop-resources.mjs`：校验并准备 Node、FFmpeg、固件、组件及许可证。
- `check-public-build-env.mjs`、`check-release-csp.mjs`：阻止私有构建输入混入公开版，校验发布 CSP。
- `sign-macos-local-app.mjs`、`bundle-macos-local-dmg.mjs`：本地签名与 DMG 封装；不代表 Apple 公证。
- `build-windows-nsis-cross.mjs`：封装 Windows x64 NSIS 安装包。
- `package-factory-release.mjs`：生成带芯片版本校验的完整烧录包。
- `prepare-p4-ready-assets.mjs`、`pack-builtin-clawpkgs.cjs`：准备设备形象和内置组件。
- `clean-skill-bytecode.mjs`：移除构建资源中的可重建 Python 缓存。
- `run-node-tests.mjs`、`test-*.mjs`：离线测试和界面验证工具。

可选的专用构建工具只接收显式输入，不提供任何账号、证书或代理配置。私有输入必须放在源码树之外，不得提交或附加到公开 Release。
