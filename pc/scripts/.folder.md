# Desktop packaging scripts

P4 voice uses the built-in native Volcengine ASR path; it does not depend on the historical LiveKit/Node service. `prepare-desktop-resources.mjs` leaves that legacy service out by default. Only an explicit `PET_MANAGER_VOICE_SERVICE_SOURCE` with its reviewed manifest SHA enables staging and checksum/production-dependency validation through `voice-runtime-resources.mjs`; bundle it via the separate `src-tauri/tauri.voice-legacy.conf.json` overlay. The base resource map has no mandatory voice-service path. No network dependency installation occurs.

Mac signing checks the legacy runtime only if present in that app. Cross-NSIS includes it only when explicitly requested. The optional Windows read-only legacy environment tool does not start services, microphones or USB. Missing optional legacy resources do not invalidate native P4 voice packages; real Windows/device acceptance remains separate.

`check-windows-p4-offline.ps1` is an explicit offline installed-client/COM checker: audited x64 Node/FFmpeg, WebView2 presence, COM enumeration, optional one-shot passive COM read with finally-close/dispose. Unique evidence directories and append-only metadata checkpoints retain failures; no serial/user payload, credentials or audio are stored. Software/COM scope never implies GUI/native voice/v3 hardware acceptance. Chinese steps live in `pc/docs/windows-p4-offline-acceptance.md`.

`check-source-safety.mjs` checks tracked and unignored publication inputs, including credential markers in binary assets. `check-source-safety.test.mjs` verifies rejected inputs and redacted diagnostics in disposable repositories; both run in source CI. Local dependency caches remain excluded by `.gitignore`.

`check-gitleaks-policy.py` verifies the exact keyboard-alphabet exception with
positive and negative scanner cases; all default detection rules remain active.
Shared preview WASM rebuilding uses LLVM/LLD 20.1.8 for byte reproducibility.
