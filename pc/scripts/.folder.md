# 构建与检查脚本

所有桌面目标打包相同的一组芯片镜像：`firmware/esp32-p4/firmware.bin`（v1）与 `firmware-v3.bin`（v3）。
版本从固件 CMake 声明读取，打包前检查各自芯片范围，不维护操作系统专用固件。
完整烧录 ZIP 按 v1/v3 命名并包含芯片核验工具，在擦除前检查实际芯片与两个镜像头。
烧录工具固定为 esptool 5.4.0，支持 P4 v3.2，并自动更新烧录目录里已有的旧工具环境。
包内中文指南说明 Python、编译工具版本、DSI 接线、v1/v3 选包和客服确认方式，附 Windows/macOS 脚本启动及故障排查步骤。
Bridge 资源检查从其 package.json 读取实际生产依赖，不再检查已移除的 MQTT 包。

本目录提供资源准备、客户端打包、固件烧录包生成及源码检查工具。脚本以向上两级目录作为仓库根目录。

运行方法见 [客户端构建说明](../README.md) 和 [运行时依赖](../docs/runtime-dependencies.md)。
