# 后台运行与菜单栏

关闭主窗口后，HachimiDock 会继续在后台运行，保留 USB 连接、状态同步和后台服务。

- 菜单栏图标提供“打开 HachimiDock”和“退出 HachimiDock”两个选项。
- 在 macOS 上，关闭窗口会隐藏 Dock 图标；从菜单栏打开窗口或再次启动应用时恢复主窗口和 Dock 图标。
- 关闭窗口不会中断传输、播放或未完成任务。真正退出时保留原有的任务和未保存修改确认，并清理后台服务。
- 显示器或缩放比例变化不会重新显示已隐藏的窗口。

使用菜单栏的“退出 HachimiDock”或 macOS Command-Q 停止程序。此功能不包含开机自动启动或阻止系统休眠。

按照项目现有的桌面端构建流程构建；Tauri 已启用 `tray-icon` 特性。
