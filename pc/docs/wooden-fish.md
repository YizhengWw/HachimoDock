# 敲木鱼：暖木色界面

## 机制清单

- 分类 tool，唯一组件 ID `wooden-fish`，从空工作包创建，不借用其他组件。
- 默认画面：暖木色底、大尺寸浅木色木鱼、从用户右下方伸来的木槌。标题与操作提示由界面绘制，主体使用独立透明位图，不显示计数。
- 唯一组件动作 `instrument.strike`，默认 SW1 短按；全局退出与实时对话绑定优先。按住不自动连敲。
- 每次合法输入立即触发一次敲击音、回弹和衰减声波；新敲击重触发视觉反馈，最多四个敲击余音同时存在，不无限排队。
- 快速连续敲击从木槌当前位置衔接，不瞬间跳回顶点；浏览器保持唯一绘图循环，不反复取消动画帧。A 音色使用同一模态合成公式生成的 8192 点只读 PCM，降低四声叠加时的实时运算开销；音量、伴奏和限幅仍实时混合。`firmware/tools/check_instrument_tone_table.py` 可重算并校验波形表。
- 打开后本地低音量原创合成伴奏淡入；离开组件淡出停止，进入语音立即停止并清除敲击，返回后重新淡入。随身听被预占后不自动恢复。
- 没有胜负、倒计时或任务结算。一次敲击的闭环为输入→声音/压缩反馈→回弹→待敲。
- 新增受控 `instrument` 组件表面，首个 source 为 `percussion.wooden-fish`，不是任意脚本/音频 URL/素材执行入口。旧固件通过独立能力 `widgetInstrument=p4-instrument-v1` 拒绝安装。
- 高精度图层、确定性动效与有界混音由产品原生模块提供，保留旧 scene 精灵配额；本版本不宣称支持任意高分辨率第三方场景或上传音频。
- `effect_volume`/`ambience_volume` 均 0–100，默认 70/18；组件说明与 PC 预览如实标注本地合成音，不冒充现场录音。

## 验证

2026-09-24 用户确认采用 A「清脆短促」。原生默认音色固定为 tuning[0]，
PC 单次敲击 PCM 从同一 C 实现生成；B/C 仅为设计试听，不是组件设置。
木槌待机位置从 y=133 抬高至 y=85，55 ms 落槌后发声并回弹。
素材压缩为 320×244 木鱼与 160×163 木槌编译图层，在原 2.5 MiB OTA 分区内使用，不变更分区或擦除用户数据。

背景音可听性修正：旧版 18% 音量后再次乘 0.24，生成伴奏的 RMS 约 -41.8 dBFS。
混音系数改为 0.60（约提高 8 dB），不改变 A 的纯敲击 PCM，也不改变包内 70/18 的配置。
PC 明确显示轻音乐启用状态，并提供不混敲击音的独立试听；音效 A/B/C 试听仍故意不含背景音乐。

最终装机版按用户要求把背景混音系数从 0.60 调到 0.80，再提高约 2.5 dB；
保留敲击音优势和限幅。PC 0.1.100 / 固件 0.7.70-p4 将木鱼纳入内置组件，
默认顺序为行情、敲木鱼、随身听、近期待办、电脑状态，再到其他组件；不固定置顶。设备和 PC 使用 #f1e3cf 暖木底色、统一阴影与配色，避免设备显示近白。

需覆盖实际 C 动画/音频核心、快敲、音量边界、退出与语音抢占、组件声明校验、PC 预览以及双芯片构建。主机/浏览器验证不等同于实机声音与帧率验收。
