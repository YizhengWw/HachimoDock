# 设备音量与共享城市位置

设备首页的“语音输入”模块下方依次提供音量和位置模块；API 配置仍在设置页。两个模块分别保存，不以未保存草稿冒充已生效状态。

## 设备总音量

设备通过 `hello.capabilities.audioMasterVolume = "p4-master-volume-v1"` 声明支持。客户端先查询确认，再允许操作 0–100 的滑杆和快捷按钮。0 使用 DAC 静音，覆盖同一扬声器输出的任务提示音、组件音效、音乐和宠物语音；各组件音量仍是下级控制。

命令 `usb_device_volume` 绑定设备身份和当前 USB 连接代次。设置只发送一次；回执超时、身份变化或读数未知时，界面停止继续设置，用户可先只读核对。界面不以滑杆草稿、SDK 缓存或默认值冒充设备实际读数。

硬件确认和保存确认分开显示。设备在空闲时防抖保存到 NVS；若仍有待保存工作，断电可能恢复先前音量。读取不触发保存或恢复默认值。实际静音、音量、音频格式切换和重启后的持久性还需要实机及人工听音验收。

## 共享位置

默认通过固定 HTTPS 服务 `ipwho.is` 估算城市；支持搜索并选择手动城市或区县，也可关闭。界面不要求填写经纬度；自动城市识别与手动选择共用同一份位置配置。服务能看到请求的出口 IP，VPN/代理可能影响估算。应用仅保留映射后的城市字段，不保存原始 IP 或原始响应；自动位置缓存仅在进程内保留。IP 结果一小时过期，时钟回退后的未来缓存不可用，失败有退避，同一时刻最多一个查询。

`shared_location_status` 是只读状态接口，`shared_location_configure` 是显式配置接口。手动城市和模式保存到本机应用数据目录，原文件损坏时停止自动定位并保留原文件，不静默覆盖。写盘不占用 UI 线程或位置缓存互斥锁。设置不属于可分发应用资源。

实时对话在每轮开始时加入城市、来源与城市级精度说明；不会把经纬度、IP 或本地路径加入该上下文。城市会提供给用户配置的对话服务。未知、关闭或过期时不猜测当前位置。

自动定位的天气组件跟随同一份共享位置。组件内显式自选城市可以作为该组件的覆盖设置；离开自动模式时清空旧自动位置缓存，自动位置与天气传输缓存不持久化到组件状态。

通用数据源 `location.current` 可供组件订阅。新设备声明 `widgetDataExpiry = "p4-data-expiry-v1"` 后，PC 才推送带 `clearOnExpire:true` 的位置快照；设备 TTL 到期或单调时间回退后清空显示和可选行，避免断连后继续显示旧城市。传统数据源未设置此选项时保留原有过期展示行为。设备最多缓存 8 个有界数据源，每源仍最多 20 行。
