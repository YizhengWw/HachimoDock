# 电脑状态与近期待办

这两个组件通过管理端获取本机数据，再经 USB 显示到设备。使用时保持客户端运行和设备连接；组件包不包含个人待办或电脑采样结果。

## 电脑状态

每两秒采样 CPU、内存、网络接口合计收发速率和开机时长，不读取进程列表、个人文件、主机名或网络地址。VPN 和虚拟接口可能计入网络合计，因此读数不是互联网测速结果。

打开组件后等待第一份数据。断开超过有效期时设备显示过期状态；重新连接后由客户端发送新快照。

## 近期待办

在 PC 组件详情页或实时对话中管理事项，支持新增、查询、修改、完成、恢复与单项删除。待办保存在本机，不随组件包分发，也不提供跨电脑同步或定时通知。

- 设备显示前 20 项：未完成优先，同组按截止时间排列，无截止时间的放后。
- 未完成为蓝色，已完成为绿色，并显示状态文字；摇杆左右翻页，主操作回到第一页。
- 时间采用带时区的记录，按电脑本地时区显示。日期不明确时需进一步确认。
- 修改和删除使用明确的事项及版本，冲突不会覆盖原数据。损坏文件不会被静默重置。

语音工具仅将本次查询或操作所需的内容提供给用户配置的对话服务。工具返回的数据不是新的执行指令；查询成功不表示写入成功，未知的写入结果不会自动重放。

## 开发入口

| 文件 | 职责 |
| --- | --- |
| `src-tauri/src/local_widget_data.rs` | 采样、快照和 USB 数据推送；音频忙时暂缓组件数据 |
| `src-tauri/src/local_tools.rs` | PC 与实时对话共用的工具入口 |
| `src-tauri/src/todos.rs` | 有界本地待办存储、原子更新及版本检查 |
| `src/component-center/LocalDataPanel.jsx` | PC 端详情与管理 |
| `builtin-clawpkgs/computer-status`、`builtin-clawpkgs/upcoming-todos` | 内置声明式组件 |

模拟、主机测试和交叉编译分别覆盖各自范围，不能替代 Windows/macOS 与设备的完整交互验证。反馈问题时提供版本、复现步骤和脱敏结果，不上传待办存储、对话正文或完整用户日志。
