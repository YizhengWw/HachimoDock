# 哈基米组件

组件使用声明式资源和宿主提供的有界能力，不随资源包执行任意脚本。服务能力仍受客户端配置、系统权限、设备连接和音频占用规则约束。

| 组件 | 用途 |
| --- | --- |
| 专注花园 | 专注计时、暂停及完成结算 |
| 哈基米小屋 | 陪伴互动及本机保存的摆设选择 |
| 活力间歇 | 简短轻休息提示，可暂停或延后 |
| 每日新知 | 分类知识与当前宠物音色朗读 |
| 灵感胶囊 | 录音转写，经确认保存或转为待办 |
| 自然声景 | PC/USB 播放及定时渐止 |
| 宠物旅行 | 设备选目的地、计时与明信片 |
| 今日气象 | 已保存城市与真实预报 |

个人笔记、待办、城市和进度属于运行时本机数据，不随组件包、源码或出厂镜像分发。停用组件保留用户数据；资源更新与状态保存分别处理，不手工覆盖正式组件库。

需要 PC 的组件必须保持客户端运行并连接设备；语音另需配置服务。外部数据失败应显示可用缓存或错误状态，不以静态封面冒充实时结果。

资源位于 `pc/builtin-clawpkgs/`。修改后按 [PetUI Skill](../skills/petui/SKILL.md) 验证、发布并同步。结构或离线回归不能代替联网、录音及各硬件组合的真实验证。
