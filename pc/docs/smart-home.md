# 智能家居

在「组件中心」下方打开「智能家居」，连接账号、刷新设备后，默认即可使用账号已授权的全部设备与场景，无需开关或逐项勾选。旧版的勾选状态不会继续限制访问；新同步的设备也自动可用。账号通过官方浏览器页面授权；将授权页给出的结果粘贴回应用完成连接。目前使用中国大陆服务。

## 使用方式

- **语音控制**：设备切到实时对话后，可说「播放一首爵士乐」「换一首歌」「把客厅灯调暗，再拉上窗帘」。明确且整条请求不超过 5 步时直接执行，可涉及多个设备。等待、条件检查也计入步数；调用已有米家场景计为一个工具步骤，场景内部动作由米家执行。
- **语音确认**：超过 5 步或保存常用任务时，哈基米先播报具体任务，用户直接语音确认或取消，无需打开 PC 页面。确认仅绑定本次对话中的这一项任务，完整播报后 60 秒内有效，执行一次即失效；修改需求、退出对话、断开账号或刷新设备会使旧确认失效。播报失败不激活确认，过长任务要求拆分；保存请求只保存、不自动执行。PC 手动草稿保留原有检查与确认控件。
- **自然语言与权限**：所有账号内设备共用“自然语言理解 → MiLoCo 查询真实能力 → 参数校验 → 执行”流程，不维护设备型号、命令措辞、歌手或曲风匹配表。确认由原生侧根据整组步骤数与保存意图决定，不再由模型额外的风险评估或 `plan` 名称触发。底层仍校验账号范围、真实能力、参数类型/范围和每轮执行次数；缺失必要参数时澄清需求或修正参数，不把校验失败变成审批。未连接或不在清单中的设备不可控制，断开账号停止访问。
- **执行反馈**：「已受理」不代表物理动作完成；只有读回匹配的属性才显示「已核验」。失败停止后续步骤，不自动重试控制、不自动回滚。停止任务不会撤回已发出的命令。
- **实时对话与语音输入**：实时对话使用内置家居工具；原来的按键语音输入仍向跟随的外部 Agent 输入文字，不自动执行家居动作。

## 当前边界

支持标准 MIOT 属性/动作和已有手动场景，具体能力以账号权限及设备公开描述为准。不是所有米家设备都开放全部能力。设备详情使用通用能力控件，不依赖特定型号。

当前任务为有界顺序任务（最多 12 步，单次等待不超过 10 秒，总执行时间受限），支持草稿排序、保存/删除、读取状态进行条件检查及失败停止。可用自然语言要求「仅当某设备状态满足条件时继续」，条件在执行时重新读取，不满足则停止。并行分支、长期定时/持续监听、外部 Agent MCP 尚未实现。应用必须运行且可联网。

## 实现与隐私

- `src-tauri/src/miot_protocol.rs`：参考 MiLoCo 的 OAuth/AES/RSA 协议；复用统一云网络客户端，校验证书，禁止 API 重定向，不嵌入固定代理。
- `src-tauri/src/smart_home_credentials.rs`：Mac 使用应用数据目录下 `private/smart-home-credentials.json`，目录权限 0700、文件 0600，原子保存并拒绝符号链接。此文件不是额外加密的保险库，同一用户权限的程序仍可能读取；不会访问或删除旧钥匙串，升级后重新授权一次。Windows 保持系统凭据存储。
- `src-tauri/src/smart_home.rs`：账号设备范围、能力参数校验、待确认计划、单次执行及本地结果记录。自然语言控制不受旧的固定音乐短语列表限制；动作参数由 MiLoCo 能力描述和大模型生成，模型没有任意任务批准接口，也不能指定任意 URL；语音确认由原生侧绑定当前任务并验证时效、会话、播报完成和一次性消费。
- `src-tauri/src/persona_llm.rs`：有界流式工具调用，支持分片参数拼接；同轮多个控制调用先合成一组，整组最多 5 步可免确认，不能每个工具调用各执行 5 步。明确尚未执行的参数错误允许修正重试；已有执行尝试或结果不明时停止，不重放、不转成重复确认任务。能力提前缓存，控制回执直接生成，不再额外调用模型组织成功话术。工具返回内容按数据处理。

家居工具是否可用、操作阶段、耗时及结果状态写入既有脱敏诊断日志，不写入账号令牌、设备标识、原始语音文本或完整工具参数。未连接账号时明确引导连接，不把缺失工具伪装成执行成功。

动作能力同时提供按 `in` 顺序展开的 `arguments` 类型定义，避免模型跨属性列表拼接参数；不根据歌曲或设备名称硬编码规则，也不替模型猜测默认参数。工具后续轮次的中间解释暂不播报，只有最终无工具回复或执行回执才进入语音；首轮普通聊天仍保留流式输出。本地校验失败新增固定错误分类及参数位置/数量元数据，不记录参数值。已开始执行或结果不确定时仍禁止自动重放。
- `src/SmartHome.jsx`：设备筛选、能力控制、权限、自然语言规划、确认和执行记录。

不向模型提供账号令牌、设备 LAN token、SSID、IP、地址或账户 UID。仅在连接账号后，在实时对话/家居助手请求中提供有界的授权设备名称、房间、家庭名称、设备标识和能力快照；状态按需查询。设备清单最多 60 项，能力附加数据限制为 24 KB，超出或缺失时按需查询。记录最多保留 50 次，账号断开后清除本机家居任务和记录。执行前持久化请求意图，异常中断后不自动重放。

## 验证

自动回归覆盖参数范围/枚举/类型、账号断开拒绝访问、旧版勾选配置兼容、新设备自动可用、计划标签可信化、手动页面轻量策略、整组 5 步边界、参数修正不消耗执行次数、已执行请求不重放、工具参数分片、前端搜索和回执文案。浏览器模拟回归见 `scripts/test-smart-home-browser.mjs`，不使用真实账号、不发送设备命令。

实际账号授权、云端业务接口、音箱播放/暂停/调音量及 v1/v3 语音入口仍须实机验收。模拟成功或编译通过不能替代实机控制结果。
