# 形象生成流程与内容审核

本页对应当前公开客户端，不包含个人图片、服务请求记录或本机验收资料。

## 流程

1. 选择图片，可选填写期望风格；人物和动物均可作为主体。
2. 按设置处理主体与背景并检查参考图；与主体一体的配饰不一概视作杂物。
3. 分析形象、规划动作并准备相应参考帧，不要求整套动作使用完全相同的首尾帧。
4. 生成并检查试片，复用合格成果后完成其余动作。
5. 下载、转换和保存可用素材；设备同步是独立步骤，需要客户端与设备保持连接。

媒体角色和参数由模型适配器决定。当前 Seedance 路径使用支持的参考图或首帧角色，不默认强制传入同图尾帧。

## 失败与恢复

- 参考图处理失败默认停止后续生成；只有用户明确允许或关闭相应处理后才使用原图，不静默回退。
- 图片处理、提示词分析、自动检查、视频提交、轮询、下载和保存分别诊断；不在公开诊断中保存图片、完整提示词或凭据。
- 保留已成功成果与已有任务标识。恢复优先查询已提交任务，不因结果未知而自动再次付费提交。
- 未创建任务与创建后结果未知分别处理，不能都当作可安全重发。

## 审核边界

请使用有权使用的素材并遵守服务商要求。图片处理和图生视频分别可能触发输入或输出审核；前一步成功不保证后一步通过。通用版权或内容错误不能直接认定为某个人脸或背景元素导致。

不把重复提交、修改尺寸、关闭背景处理或静默更换模型包装成绕过审核的方法。客户端不代替权利人完成肖像授权；需要额外授权时按服务商公开流程处理，或使用已获授权的其他素材。也可提供符合要求的 MP4，通过形象画廊导入。
