# 参考图审核与自定义动态形象

## 如何判断失败环节

图片背景处理和图生视频是独立的云端请求。本地参考帧合成不涉及云端审核。

- 图片处理：Seedream `/api/v3/images/generations`，失败时可能回退使用原图。
- 图生视频：Seedance `/api/v3/contents/generations/tasks`。`volcano submit HTTP 400` 表示视频任务提交被拒，不能据此判断图片处理是否成功。
- 请求中的 `first_frame`、`last_frame` 可以引用同一张图片，用于循环动画；两个字段不意味着上传了两张不同的原图。

客户端仅在平台明确提到真人或人脸时提示人像审核。通用内容、版权或隐私错误不会一概归因为人像问题，也不能据此判断画面中具体哪个主体触发了审核。

## 遇到审核拒绝怎么办

请使用有权使用且符合平台要求的素材；如有异议，可携带平台请求 ID 联系服务商复核。当前客户端未接入平台的真人授权素材库，不保证真人照片能够直接生成视频。图片处理成功也不代表视频审核一定通过。

你也可以使用有权使用的素材，自行生成动态形象并导出 MP4，在「形象画廊 → 新建自定义形象 → 自定义上传视频」中上传；其他动作可在形象详情页通过「上传 MP4 替换」补充。此方式不承诺其他平台一定能生成，也不免除素材授权要求。

共用参考图明确被拒后，客户端停止提交剩余动作，保留已完成的结果，避免无意义地重复请求。改变尺寸、时长或反复重试不是审核问题的解决方法。

## 实现与测试

错误分类位于 `src/lib/avatar-pipeline/providers/volcano.js`，生成流程位于 `src/lib/avatar-pipeline/run.js`，上传入口位于 `src/CustomAvatarWizard.jsx`。回归使用模拟响应，不上传用户照片、不调用付费接口。

平台流程参考：[可信素材库及真人授权](https://www.volcengine.com/docs/82379/2315856?lang=zh)。支持范围以所选模型和账号权限为准。
