# 实时对话音频链路

设备负责采集、播放参考、AEC、降噪及 VAD，PC 负责识别、对话、合成与任务路由。只有设备声明必要能力时才启用双向收音；旧设备保持兼容的保守路径。

PC 使用有界句首缓存和识别确认处理插话。取消播放会丢弃旧代次的 PCM 与字幕；AEC 或传输错误分别诊断，不把原始播放回声直接当作用户指令。音频、渲染和存储均保留资源边界，不通过关闭 AEC 或删除保护掩盖问题。

诊断只保留阶段、数量、耗时与白名单状态，不保存原始录音、完整转写或凭据。主机回归不能代替近远距离、背景噪声、播放中插话与长时间多轮对话的真实声学验证；公网、麦克风和设备播放测试需要显式配置与允许。

使用说明见 [实时对话](realtime-chat.md)，第三方许可见 [THIRD_PARTY_NOTICES.md](../../THIRD_PARTY_NOTICES.md)。
