# 自选股行情与组件实时数据

## 使用方式

1. 「自选股行情」已内置于 PC 和设备，默认排在组件列表第一位；点击 PC 的卡片，在详情弹窗管理股票。新用户默认包含小米集团（港股 01810）和阿里巴巴（港股 09988）；已有自选列表不覆盖，主动删除后不会自动补回。
2. 输入中文名称或代码，下方自动出现联想结果（包含市场和代码），点击即可添加；也可选择市场直接输入代码。支持沪市、深市、北交所、港股和美股，最多 20 只；删除和排序自动保存。通过弹窗底部按钮同步组件到设备。数据能力从 0.7.60-p4 起支持，顶部日期需要 0.7.61-p4；v1/v3 使用对应固件。
3. 在设备打开该组件，每页显示 5 只股票；摇杆左右翻页，主操作回第一页。组件退出仍使用设备既有退出按键。
4. 保持 PC 应用运行和 USB 连接。行情由 PC 获取；设备不需要联网。修改自选股后无需重装组件。

PC 正常网络下每 2 秒批量请求并向设备更新行情，手动刷新最短间隔 2 秒；请求不重叠，慢请求会延后刷新，请求失败会退避，最长 32 秒。行情并非交易所直连报价，可能延迟，必须以每只股票显示的行情时间为准。休市时保留服务返回的最后报价，不伪造今日实时价格。当前不提供证券账户登录或交易功能。

设备仅在顶部显示北京时间日期，行内保留代码/币种，不显示日期或时刻；原始行情时间可在 PC 详情中查看。仅股价与涨跌幅上涨红、下跌绿，名称等保持正常色。零/缺失涨幅、过期、周末、当地开盘前或没有当地当日盘中报价时保持正常色；午间和收盘后的当日报价保留涨跌色。按上海/纽约时区判断（包含美国夏令时）；节假日依赖提供方没有当日报价来识别，不声称提供完整交易所交易日历。

开盘时刻采用常规股票交易时段，参考 [上交所](https://english.sse.com.cn/start/trading/schedule/)、[港交所](https://www.hkex.com.hk/Services/Trading-hours-and-Severe-Weather-Arrangements/Trading-Hours/Securities-Market?sc_lang=en)、[NYSE](https://www.nyse.com/trade/trading-information)。

## 通用数据接口

v4 组件可声明：

```json
{"data":{"source":"stocks.watchlist","page_var":"list_page"}}
```

`list_page` 必须是组件的整数变量，通过标准 transition 加减实现分页。数据列表不混用 scene/game 渲染；原有未声明 data 的组件不受影响。当前内置数据源仅有 `stocks.watchlist`，后续数据源需要在 PC 实现受控提供器，不接受组件内 URL、脚本或任意网络请求。

USB topic `widget/data` 的 payload：

```json
{
  "schema": 1,
  "date": "2026-09-21",
  "source": "stocks.watchlist",
  "ttlMs": 30000,
  "status": "empty",
  "message": "请在 PC 组件中心添加自选股",
  "rows": []
}
```

每行必须包含 `id`、`label`、`value`、`detail`、`meta`、`tone`；字符串 UTF-8 字节上限依次为 23、36、24、24、63，tone 为 -1/0/1。source 为 1–47 字节小写 ASCII 字母、数字、点、横线或下划线。最多 20 行，ID 不重复，status 为 ok/error/empty，TTL 范围 5000–300000 毫秒。设备最多缓存 4 个命名源，只驻留 RAM，整包验证失败不更新数据或有效期。

PC 关闭或断开 USB 后，设备 30 秒没有收到有效快照即提示过期。正常行情不显示底部来源文案；空列表、网络错误与数据过期提示保留。上游失败时 PC 保留最后报价并逐项标记旧数据；部分成功只更新成功项。后台推送避开固件、形象和组件文件传输锁，不改变现有大文件传输协议。

`date` 是可选 `YYYY-MM-DD` 字符串（最多 10 字节），旧发送端可以省略；不从接收时刻伪造报价时刻。联想词仅发送到腾讯固定 HTTPS 检索接口，返回内容作为 JSON 字符串解析，绝不执行 JavaScript；最多展示 12 项，添加前再验证实际报价。

## 数据与安全边界

- 自选代码/顺序存于应用数据目录 `stock-watchlist.json`，原子替换；报价不写入文件。安装资源不包含用户自选列表。
- 网络仅请求固定 HTTPS 腾讯行情和联想接口，传递股票代码或检索词；不传 API Key、证券账户、设备身份或聊天记录。共享应用 TLS/企业 CA 配置，但不降低证书验证、不允许重定向。
- 限制代码格式、股票数量、响应体大小、超时和重试频率；删除/排序使在途旧请求失效。
- 行情接口的可用性、延迟及再分发授权以提供方规则为准；此实现不代表取得商业行情授权。

## 验证

Rust 单元测试覆盖代码校验、GBK、价格精度、持久化、旧响应隔离及部分失败；显式 ignored 联网测试使用公开示例代码、不读取用户配置。固件 host C 测试覆盖原子更新、分页、数据源隔离和 TTL。浏览器模拟测试覆盖添加、重复、排序、删除、过期展示和窄屏布局，不访问真实设备。

完整上板端到端验收还需升级对应芯片固件，在设备切换到行情组件，验证 USB 断开过期及重新连接恢复；构建通过不能替代实际设备验收。
