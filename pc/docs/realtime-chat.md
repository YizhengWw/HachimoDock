# 实时对话：使用与排查

连接米家账号后，实时对话可用自然语言控制所有账号授权且开放 MIOT 能力的设备。设备与参数来自 MiLoCo 能力发现，不使用固定口令匹配；选歌保留歌手、歌名、曲风等完整需求。整条明确请求最多 5 步时直接执行，可涉及多个设备；超过 5 步或保存任务由哈基米播报任务并请求语音确认，不需要 PC 点击，也不再由模型额外的风险评估触发确认。账号、能力和参数校验仍保留；参数错误且尚未执行时允许修正重试，不消耗执行次数，已有执行尝试或结果不明时不重放。确认限当前对话，播报完成后 60 秒有效，取消、修改请求、退出或过期后失效。能力在进入对话时后台预热；可用快照直接供模型使用，回执不再请求一轮模型。官方 DeepSeek Flash/V4 Pro 与方舟 Seed 2.0 的实时请求禁用思考，避免短 JSON 决策耗尽输出预算。家居工具可用性及执行阶段记录在脱敏日志中；没有账号权限时会提示连接，不声称已经控制成功。Mac 家居令牌使用仅当前用户可读写的本地文件，不再读取钥匙串；从旧版本升级需重新连接一次米家账号。

双向语音需要配套支持 AEC/VAD 的新客户端与固件，不能仅更新 PC。公开安装包不内置 API Key、固定代理或企业证书；需要自行配置服务 Key。

## 使用

首页、API 配置和“人设与声音”的操作提示会跟随当前按键配置；以下按键为默认设置。修改后需同步到设备，未绑定时页面会提示设置快捷键。页面“如何使用”中可以查看详细步骤。语音输入是给 Agent 追加文字并手动确认发送；实时对话是直接和设备上的宠物聊天。

1. API 配置中填写一个语音 Key 和一个对话大模型 Key。语音识别与合成共用同一个 Key，固定使用 ASR 2.0 与 TTS 2.0，不需要选择版本或填写资源 ID；账号仍需分别开通对应服务。旧配置优先保留识别 Key；仅配置过合成 Key 时自动迁移，迁移写入失败会保留原 Key。
2. 在形象画廊设置“人设与声音”。音色下拉框包含[官方 TTS 2.0 音色目录](https://docs.volcengine.com/docs/DoubaoVoice/Tonelist-1?lang=zh)的 445 个音色（目录更新于 2026-09-15），按语言分组，可搜索名称、语言或音色 ID。仅限单向流的 15 个音色自动使用对应接口，无需设置协议。实际可用性仍取决于账号开通权限。旧版已保存的兼容 ID 保留；仅已知的旧版不兼容音色迁移到默认 Vivi，并显示迁移提示。保存后写入 persona-voice.json，不覆盖人设或其他素材。已有复刻音色 ID 保持不变，使用 seed-icl-2.0。
3. 在设备宠物界面长按 SW2（默认“实时对话”快捷键），或在 PC 控制台点击开始。准备完成后进入聊天，配套双向语音固件也可以打断开场白；再次长按 SW2 或点击结束可停止，包括合成、思考与播放期间。已保存的自定义按键不覆盖，可在按键配置中手动将 SW2 长按设为“实时对话”。
4. 配套 AEC/VAD 固件支持在宠物回复时开口打断，无需先说固定口令；开场白、思考、合成与播放阶段均可打断。旧固件保留“等宠物说完再说”的兼容模式。60 秒无语音自动结束。开发验证与实机验收状态见 [双向语音](realtime-duplex.md)。

### 实时字幕（需配套新版客户端和固件）

进入实时对话后，设备复用原有气泡卡片，边框变为蓝色。听你说话时显示识别文字；宠物回复时只显示宠物当前说的内容，不保留用户摘要。字幕按音频播放进度逐句切换，较长内容自动翻页。准备、思考和连接失败也在同一气泡内提示。

实时对话期间隐藏 Agent 气泡、状态及统计，Agent 跟随在后台继续更新。摇杆只回看本次对话最近 8 条字幕，不切换 Agent 会话；确认键不会向 Agent 发消息。默认 SW3 返回或 SW2 长按退出，PC 结束按钮也有效。新字幕到达后自动回到当前内容。

退出或断开连接后清空设备内存中的字幕，恢复当前 Agent 跟随画面，不恢复已过期的旧气泡。字幕不写入设备 Flash 或诊断日志。PC 对未声明字幕能力的旧固件仍使用原有状态提示。

## 公司网络与代理

在「API 配置 → 对话大模型 → 云服务网络」中设置，内外网使用同一套代理逻辑。每台电脑独立保存配置，安装包不会携带打包电脑的代理地址。公开版不内置企业证书；专用内部版可以额外内置经确认的企业 CA 公共证书链，只供应用验证 HTTPS，不修改系统信任。

- 默认「跟随系统」：读取当前应用进程的标准代理环境变量，或本机系统 HTTP/HTTPS 代理；使用操作系统信任证书。由 IT 安装并信任的企业根证书可直接使用。
- 若公司没有配置系统代理，在「手动配置」中填写 IT 为这台电脑提供的 HTTP/HTTPS 代理地址。不要复制另一台电脑的本地代理端口。代理暂不支持内嵌账号密码；PAC 自动脚本、特殊代理认证需由 IT 提供兼容的连接方式。
- 若 HTTPS 检查要求企业 CA，可导入 IT 确认可信的 PEM 公共证书；不接受私钥、不修改系统证书、不关闭 TLS 校验。移除导入证书并保存即可恢复使用系统证书及内部版的内置证书。
- 保存后下一次请求生效，点击「测试已保存配置」分别检查火山方舟与 DeepSeek。测试不发送 Key 或对话内容；HTTP 401 表示已收到 HTTPS 响应，但实际对话仍需有效 Key、模型权限及额度。HTTP 403 不视为测试成功。
- 系统代理变化最多 60 秒刷新，点击测试或保存可立即刷新。不会扫描代理端口，也不会在代理失败后擅自改为直连。

这些设置同时适用于模型列表、图片/视频生成、素材下载、ASR/TTS 及实时对话。保存后新的请求生效，正在进行的语音连接需重新进入；不改变设备和本机 Agent 的直连逻辑。公司防火墙必须允许访问对应服务；设置不能替代网络授权。新电脑安装后应先测试两家服务，再进行一次真实对话验证。网络测试不发送 Key，也不验证生成或语音服务的实际调用权限。

## 实际实现

设备麦克风 + 实际扬声器参考 PCM → ESP-SR AEC/降噪/VAD → USB → 豆包流式 ASR → OpenAI 兼容流式 LLM → 豆包 TTS → USB → 设备扬声器。支持新能力时上、下行并发，用户语音优先取消当前回复；旧固件使用原能量 VAD 与半双工路径。

不运行 LiveKit、Python sidecar，不写入代码 Agent 的会话。人设、音色、语速及音量保存后刷新当前形象配置；正在进行的对话从下一次回复使用新参数，不打断已开始播放的声音，无需切换形象或退出对话。新会话总是重新读取磁盘配置。设备 PCM 为 16 kHz、单声道 S16LE，JSONL/base64 传输；播放环形缓冲在 PSRAM 懒分配，约 200 ms 起播。此实现与早期设计稿中的架构设想不同，以本文和代码为准。

实时对话期间暂停普通状态提示音，避免“聆听”动画的提示音触发半双工收音屏蔽。开场白先完成语音服务检查，再打开持续收音。

0.1.61 优化回复延迟：仅对官方方舟端点的 Doubao Seed 2.0 模型关闭深度思考；其他模型/自定义端点不注入专属参数。复用 HTTPS 连接；首个逗号短句满 8 字即可开始合成，后续短句仍保持原阈值。不缩短停顿检测，不更换模型，不影响 Agent 的推理设置。

0.7.57 将 ES8311 输出音量设为 100（标准音量曲线 0 dB；此前 60 为 -20 dB）。不额外放大 PCM；人设中手动设置的相对音量保持不变。`audio/status.playbackVolume` 返回读取到的硬件音量，v1/v3 共用此逻辑。

## 日志与错误

- 漏识别诊断：`vad_window` 每 250 帧汇总设备语音标记、被 PC 能量门槛拒绝的帧数、回复阶段帧数、峰值 RMS 和触发次数；`asr_audio_submitted` 表示已交给识别器队列的帧数/字节数，不代表云端已确认接收；`asr_empty` 明确记录无文本结果并在设备提示重说。音频发送失败不再静默忽略。
- 当前源码区分安静聆听和回复时的触发门槛，并保留 600 ms 句首；不修改普通 Agent 按键语音。固件算法、官方例子对照和实机验收边界见 `realtime-duplex.md`。

- PC：应用数据目录 `logs/realtime-chat.jsonl`，超过 1 MiB 轮转为 `realtime-chat.previous.jsonl`。Unix 新建文件权限 0600。
- 字段：时间、会话 ID、阶段、错误类别、轮次、字符/字节计数。不记录 Key、提示词、完整对话或 PCM。
- `asr_final.elapsedMs`：结束收音到最终识别；`llm_first_delta` / `llm_first_sentence`：大模型请求到首字/首段；`tts_first_pcm`：单段合成开始到首段音频；`turn_completed.elapsedMs`：发起大模型请求到播放等待完成。真正起播以设备 `playback_started` 为准。
- 设备：串口 `pet-p4-audio` 日志，以及 `audio/diagnostic` 结构化事件。PC 自动汇总到上述日志。事件含启动、收音、播放开始/完成、缓冲欠载/溢出、指令拒绝和结束；正常音频帧不逐帧写日志。
- 支持字幕的固件由 `playback_completed` 确认实际播放结束，确认超时提示连接错误，不按估算时长提前清除字幕。旧固件此时恢复聆听，新双向固件在播放期间也持续聆听；家居确认仅在完整播报后激活，打断会使其失效。
- 双向模式等待 ASR 最终结果时仍消费麦克风帧。后续语音保存在至多 576 帧的临时队列中，先交给 VAD 再发起回复；队列满或 AEC 标记失效会明确结束会话，不静默丢掉追加的话。
- `audio/query` 的 `audio/status` 包含播放缓冲、接收字节数和欠载计数。设备日志不写 Flash；连接期间由 PC 持久保存。
- 失败快照在 PC 保留，控制台顶部和实时对话卡片显示错误。设备失败提示保留约 8 秒后回到正常画面。
- `55000000 / resource ID is mismatched`：音色与资源不对应，不应重复用同一参数重试。
- HTTPS 证书验证失败：检查系统时间、可信证书和网络，不关闭验证。内部版只允许内置经确认的 CA 公共证书，不包含私钥或固定代理。

## 验证

离线：Node 人设/契约测试、Rust VAD/取消/资源映射/日志隐私测试、固件协议测试。

真实云服务验证需显式设置 `PET_REALTIME_SETTINGS_DIR` 指向已配置的应用数据目录，再运行忽略的 `live_seed_tts_2_catalog` / `live_voice_pipeline` Rust 测试。前者验证音色；后者用合成的测试语音跑通 TTS→ASR→LLM→TTS。不会打印 Key，不代替真实设备麦克风和扬声器验收。
