# 随客户端分发的组件生成 Skill

`petui` 支持游戏、工具与 PC 提供实时数据的列表。入口按需路由到 `references/live-data.md`，当前已实现 source 为 `stocks.watchlist`，其它来源先补齐产品提供器。

结构校验拒绝无效 data、旧设备能力、错误分页变量和 scene/game 混用；`smoke_test_widget_game.py` 的 data-list 分支执行真实 transition，检查 0/1/6/11/16/20 行的页面可达性及输入反馈。发布器沿用同一测试入口，因此实时列表不再跳过自测；结果明确未验证网络或实机。

本目录由应用 Skill 安装流程复制到对应 Agent，元数据保留自动发现；不含用户列表、Key 或内部地址。
