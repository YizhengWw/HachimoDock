# 宿主字段与设备程序/表单的隔离（实验，默认关闭）

只有实际设备协商 `widgetVariableOwners="p4-variable-owners-v1"`，才允许安装
以下声明；版本号、PC 预览成功或伪造能力文件都不能代替设备授权。

```json
{"host":true,"host_context":"p4-host-context-v1",
 "ownership":{"engine":"p4-variable-owners-v1","host":["remoteStep"]}}
```

`ownership` 精确包含 engine/host。host 为已声明变量的非空、唯一子集，沿用总共
八个变量及现有内存、JSON、节点、输入和程序预算。需要 v4、app surface、变量绑定
和 input v1。PC 声明使用组合 v2/v3，bindings 必须恰好覆盖 host 子集；只有 host.
动作交给 PC 服务，其他动作由同一设备原生实例处理。旧 host 包仍由宿主管理所有
变量和动作，旧本地包语义不变；不能据此开放 scene/game/media/instrument/data/local。

设备程序、表单、transition、tick、persist 的写入字段必须互不冲突。宿主字段不能
作为程序输出、表单角色/键盘角色、存档目标或原生 transition/tick 的写入目标。
当前原生条件、赋值源和 dashboard 也不能引用宿主字段，避免错误地读取初始值；
surface/Canvas 可分别绑定两类字段。宿主 dashboard 不替换原生 dashboard。

程序动作可以读取宿主 int。一次派发将所有依赖从同一新鲜、类型正确的快照捕获，
按已声明范围钳制，再交给实际有界队列。没有快照就拒绝本次动作，不补发、不读取
初始值冒充远端结果；已接收的事件不会被后续回复更改。纯本地动作不等待宿主，
也不受宿主动作列表或服务停用牵连。宿主字段是易失数据，不写回原生模型/存档。

依赖宿主的点击、显隐、滚动和列表记录保留发布代次保护：按下到松开之间发生更新
或先改后改回，旧点击均失效。纯本地动作/几何不因无关宿主刷新而取消。PC 轮询保留
原生程序实例、表单草稿和提交状态，不重新套用 initialApp。宿主失效不等于停止
全部本地计算；原有隐藏、显式停止、音频撤销和资源生命周期规则仍然有效。

普通固件仍关闭 `PET_VARIABLE_OWNERS_ENABLED`。私有候选的启用不是普通固件推广，
也不表示后台网络、任意服务、外设、声音或 AEC 已验收。离线自测只用明确标记的
声明初值验证原生路径，hostActionsContractOnly/hostServicesVerified=false 如实保留；
真实提供器、安装、串口、性能、保存恢复和前后台并存必须另外验证。

混合字段的新鲜度只来自实际接收的变量发布：发出宿主命令或进入 pending 不会
延长十秒有效期，也不会让旧输入/旧手势重新有效。依赖宿主的程序参数与确认必须
在同一发布代次下读取；纯本地确认不因无关宿主刷新取消。预览中的实体按键入口
与触屏共用确认控制器，确认期间 SW1/SW2 沿已声明映射执行确认/取消，不绕过门禁。
