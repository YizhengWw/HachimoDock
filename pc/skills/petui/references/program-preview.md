# 受限整数程序的离线创作与同源预览

本文是纯程序工程验证入口，不是已开放的组件引擎。另有
[component-program.md](component-program.md) 中的候选组件接入、输出绑定、调度与
私有存档路径；其执行门禁仍关闭。不能把程序写进现有组件后声称设备可运行。
生产 PROGRAM/PERIPHERAL 配额仍为零；P4 时间/提交互斥/音频门禁尚未通过。

本机 `node scripts/program-preview.mjs` 从 stdin 读取一个 JSON，字段只有
`program`、`events`、可选 `seed`、`quantum`、`outputLimits`。不读任何配置、个人文件或凭据，
不联网、不接设备、不保存数据、不生成组件包。输入至多 64 KiB、1–32 个事件，
错误只返回固定错误码。输出是本次本地模型/回执，包含用户输入数据，不要作为
封面、组件默认值、社区资源或仓库素材发布。

`program` 恰好为：

```json
{"engine":"p4-integer-program-v1","schema":1,"cells":1,"fuel":64,"code":[
 ["CONST",0,0,0,0],["LOAD",1,0,0,0],["EVENT",2,0,0,0],
 ["ADD",1,1,2,0],["STORE",0,1,0,0],["OUTPUT",0,1,0,0],["HALT",0,0,0,0]
]}
```

最多 64 个 int32 存储格、16 个寄存器、8 个 int32 输出、256 条指令，每事件总燃料
1–4096，每片 1–64 条指令（quantum 默认 64）。每条指令为五元组
`[操作码,a,b,c,立即数]`，完整语义以 `pet_p4_program_core.c` 为准，不另写 JS 解释器。
允许 HALT/CONST/MOVE、整数算术、比较、分支、LOAD/STORE、EVENT/OUTPUT；
禁止 INTENT，即使位于不可达代码。没有脚本、指针、递归、网络、音频或外设操作。
时间必须作为显式事件输入，不能把该算例等同于后台时钟调度已经完成。

事件是至多 4 个 int32 的数组；事件顺序号由本次 CLI 从 1 顺序产生。
分片中的状态不对外发布，整次成功提交才增加 revision。除零、越界、溢出和
燃料耗尽保留原状态；CLI 在第一条非 committed 回执后停止，不继续后续事件，
不自动重试。JS 预览 API 的 `pump()` 只走一个 begin/分片/commit 阶段，
浏览器调用方须在 UI 回合之间让出执行权，不能同步循环耗尽全部燃料。

`seed` 为 null/省略时，仅表示这次离线实验明确建立一个全零新模型，绝非恢复设备
存档失败时的兜底。提供 seed 时必须精确包含 schema/revision/cells/values/outputs，
schema 与 cells 必须匹配；values 恰好 cells 项、outputs 恰好 8 项，均为完整 int32。
revision 可为 UINT32_MAX，须原样保留，下一事件返回 overflow，不能重置。
不恢复在途队列、旧回执或外部任务，不提供迁移推断或重放。

可选 `outputLimits` 为恰好八项 `{ "min": -100, "max": 100 }` 的数组，边界为
完整 int32 闭区间。原生运行时复制边界，调用方后来修改数组不能放宽约束。
提交前同时检查全部输出；任何一项越界，存储格、输出、revision 均不发布。
新约束与旧 seed 不兼容时拒绝启动，不截断、不清零、不覆盖存档。无 seed 的全零
模型也必须满足约束，不会为了启动而自行选择初值。省略约束保持旧的完整 int32
语义。设备将来接入时，边界须由当前已验证的接收模型决定，不是组件提供的授权。
本文纯程序入口不绑定 UI；候选组件接入另有独立接收模型与门禁，未开放游戏/服务混用。

JS 离线 API 另支持可选 `clock:{nowMs,timers}`，不是 CLI 的新字段或自动后台任务。
`nowMs` 是显式的非负 safe integer 单调毫秒数；timers 为 1–8 项
`{id,delayMs,intervalMs,words}`，ID 为互异的 1–65535，delay/interval 为 uint32，
interval=0 表示单次，其余须至少 100 ms，words 最多四个 int32。它们与固件编译的
`pet_p4_program_timers.c` 共用实现，没有另写 JS 定时器。程序宿主统一分配事件序号，
调用 `tick(nowMs,sequence)` 每轮至多入队一件工作，不执行程序；仍须另行分片 pump。
延迟的周期事件合并错过的周期、保持原相位，不追赶补跑；同轮到期轮转公平投递。
队列忙/满不消耗事件，已接受的事件不因后续程序失败而重新投递。时钟倒退、重复序号
或所有权失效会锁存停止；恢复时钟/音频不能自动重启。取消同时停止该预览的调度和
运行时。原生调用方必须在同一生命周期锁内配对取消调度器和宿主。
这是有界调度核心及离线入口，尚非开机恢复、持久闹钟、通用事件总线或设备 RTOS
后台接入；不允许从存档自动重放队列，也未开放 PROGRAM 配额。P4 tick 最坏耗时、
音频争用和真正设备宿主调度仍需独立验收。

创作代码编码为既有 P4P1 数据镜像，使用原生 C 解码器验证结构和 CRC；CRC 不是签名
或执行授权。预览只实例化随产品构建的固定 C 解释器 WASM，不接受用户 WASM。
每实例固定 256 KiB、零 imports、不可增长；旧组件不会因此实例化该核心。
取消会锁存，旧实例/缓冲不能恢复新实例权限；结果未读取时维持回压。

`contracts/program-preview-v1.json` 的十类纯逻辑用例覆盖分类汇总、时间区间、复习
间隔、成长值、背包槽、角色阶段、整数运动、条件路由、集合归约和显式时间冷却。
原生 C 与预览在 quantum 1/7/64 下逐项比较最终状态、回执和燃料。它们不是十个
已完成的 UI/游戏产品，更不是图像、P4 性能、后台运行或声音/AEC 实机验收。

重现产品解释器：`node pc/scripts/build-program-runtime.mjs --check`；本机已有
Clang/wasm-ld 才运行，不下载工具。源码及机械镜像须同时通过回归。
