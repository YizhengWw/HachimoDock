# 有界通用绘图（候选，默认关闭）

这是绘图数据解释器，不是包内代码、SVG/HTML、脚本、DMA 或帧缓冲指针。
设备与预览复用 `pet_p4_canvas.c`；PC 只装载产品自带的固定内存、无 import WASM，
组件包本身不能携带 WASM。没有组件 ID 专用绘制分支。

尚未通过 P4 帧耗时和语音/AEC 门禁。正常目标 `PET_CANVAS_ENABLED=0`：
不报告 `widgetCanvas`，不接受带 canvas 的布局，surface 结构不增加绘图存储。
只有独立 `esp32_p4_canvas_candidate` 构建打开它；该目标不用于公开包或 OTA。
离线测试/目标编译不等于可以在普通设备上开放此能力。

## 声明与预算

需 `p4-app-surface-v1`、`p4-app-graphics-v1` 和 `p4-variable-bindings-v1`，
以及实际设备能力 `widgetCanvas=p4-canvas-v1`。PC 同步在传输前核验能力，
不能凭固件版本号猜测。旧 surface、图片/字体、变量、节点和存档语义不变。

`surface.canvas` 必须包含 engine/x/y/w/h/commands，可选 page，不接受其他字段。
engine 固定为 `p4-canvas-v1`；区域完全在 640×480 内，宽 1–320、高 1–240。
page 沿用节点语义：0–3 为已声明页面索引，4/省略为通用页。
这一个绘图区域是固定屏幕坐标，不冒充多个滚动 Canvas 或任意手机 UI。

commands 为 1–16 个按序执行的对象，颜色是 RGB565 整数 0–65535：

| op | 精确字段（除 op/color 外） | 绘制 |
| --- | --- | --- |
| line | x/y/x2/y2 | 一像素直线，包含两端点 |
| rect | x/y/w/h | 填充矩形 |
| circle | x/y/r | 填充整数圆 |

坐标相对绘图区域。字面量 x/x2 范围 0…宽−1，y/y2 范围 0…高−1；
w/h 为 1…区域宽/高，r 为 1…floor(min(宽,高)/2)。
这些操作数也可写成恰好 `{"var":"已声明整数名"}`；最多 8 个不同名字，
仍占原有 runtime 8 个变量的额度，不增加第九个变量或表达式执行入口。
动态坐标夹到 0…边长−1，动态尺寸夹到 0…最大尺寸；0 尺寸不绘制。
超出区域的矩形/圆被裁切，永不写区域之外；线段使用确定性的有界整数步进。

软件工作预算是最多 2048 次矩形 span 输出：每条线按 max(区域宽,区域高)
计最坏成本，矩形为 1，圆为 2r+1（绑定半径按最大半径）。超预算在绘制前拒绝，
不先画一半再报错。它限制软件工作量，不是毫秒级性能保证。
紧凑 runtime 仍受 8191 字节限制；不扩大图片、音频、节点或执行队列配额。

## 所有权、快照与失效

命令由现有已验证 surface/lifecycle 拥有。组件不能提交地址、原生回调或缓冲区，
只能改变受控整数。输出复用宿主已有 framebuffer，不为组件分配屏幕大小的缓存。
绘图处于静态背景之后、交互节点之前，不覆盖外层确认/连接/退出 UI。

设备本地值在同一个 runtime 锁下取样；PC 宿主值在同一个宿主锁内一次性捕获，
避免一张图混用两个回包的坐标。缺失、类型错误或过期快照不画，不伪造 0 值；
预览报告 `canvas_snapshot_unavailable` / `canvas_snapshot_invalid`，错误不包含原值。
预览切换声明、卸载或异步加载过期时丢弃旧结果。静态完整帧缓存精确比较绘图命令、
当前变量、页面和快照可用性；变量/可用性变化会使旧帧失效。

原始 JSON 中的 NUL 转义在新绘图 runtime 入口拒绝，不能利用 cJSON 的字符串
终止规则将一个变量名解释为另一个。未知操作、额外字段和非法变量类型均拒绝。

## 验收

共享声明向量为 `contracts/canvas-v1.json`。验证原生解析/渲染、C/WASM span 与
像素对照、八向线段端点、极值/随机变量、预算/裁切、缓存失效、旧布局默认关闭，
以及实际 AppSurface 变量更新、页面切换和不可用状态。运行
`node scripts/build-canvas-runtime.mjs --check` 检查二进制和技能侧适配器镜像。
这些结果不替代设备屏幕、长帧、输入、录音/播放或 AEC 的实机验收。
