## Architecture
- 2026-08-05 bundled P4 firmware distribution: the release ESP-IDF application
  image is stored as a Git LFS desktop resource so packaged Pet Manager builds
  can offer version-gated USB upgrades without relying on an external file.
- 2026-08-04 branch-boundary safety: local internal-build credential and state
  files remain ignored on every branch so switching back to `main` cannot
  expose or accidentally stage private packaging material; the internal build
  implementation itself remains isolated from `main`.
- 2026-08-04 P4 verification entry: the root validation guide now exposes the
  canonical Windows `p4.ps1` build, guarded flash, and explicit factory-reset
  commands while the runtime README retains their detailed safety contract.
- 2026-08-03 macOS local-build safety note: the public build entry now requires
  `npm run build:mac:local` for installed development packages and
  Accessibility testing, preserving one verified local designated requirement
  across rebuilds; plain `build:mac` is reserved for stable Developer ID
  release signing.
- Scope: root
- Function: Single-repository workspace for the HachimoDock desktop app, bridge sidecar, ESP32-P4 firmware, bundled PetUI skill, and public documentation.
- Sync: if this folder changes, update this file immediately.
