# Security Policy

## Reporting a vulnerability

Do not publish credentials, private logs, exploit details, or personal data in
a public issue. Use this repository's private GitHub Security Advisory reporting
flow instead. Include the affected Pet Manager version, operating system,
firmware version, reproduction steps, and the minimum logs needed to investigate.

## Supported releases

Security fixes are provided for the latest published desktop and firmware
release. Older builds may be asked to upgrade before a report is investigated.

Official public desktop packages never include HachimoDock internal API keys.
Provider credentials configured by a user remain that user's responsibility.
